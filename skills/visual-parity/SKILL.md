# Visual Parity Verification Skill

## Guidelines
- Check spacing & typography: Airbnb uses Circular / Plus Jakarta Sans font family with tight letter-spacing on headers.
- Hover states: Smooth 300ms transition on photo hover with subtle dark overlay or zoom (`scale-105`).
- Border radii: `rounded-2xl` on photo grid, `rounded-3xl` on sticky reserve widget.
- Shadows: Soft elevated shadows on floating buttons (`shadow-md`, `shadow-xl`).
- Accessibility: Focus traps on open modals, clear aria labels.

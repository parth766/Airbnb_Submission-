# AI Sub-Agent & Workflow Configurations

This project utilizes AI agentic workflows for automated code generation, visual parity auditing, WCAG 2.1 AA accessibility enforcement, and production architecture planning.

## Defined AI Agent Roles

- **UI Developer Agent (`.gemini/agents/ui_developer.md`)**: Responsible for building React + TypeScript components, enforcing Tailwind CSS pixel parity, and handling Framer Motion overlay animations.
- **Accessibility Auditor Agent (`.gemini/agents/accessibility_auditor.md`)**: Responsible for auditing ARIA roles, keyboard navigation (`ArrowLeft`, `ArrowRight`, `Escape`), focus trapping, and contrast.
- **Code Reviewer Agent (`.gemini/agents/code_reviewer.md`)**: Enforces strict TypeScript interfaces, clean code modularity, zero runtime errors, and dry component structure.
- **System Architect Agent (`.gemini/agents/system_architect.md`)**: Designs the high-level architecture diagram and documentation for a global vacation-rental marketplace scale.

## Project Skills
- `skills/airbnb-cloning/SKILL.md`: Comprehensive instructions for Airbnb listing page visual & behavioral replication.
- `skills/visual-parity/SKILL.md`: Standards for layout, spacing, typography, colors, and asset extraction.
